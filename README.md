# Faiz Hasan – Personal Portfolio Website

This is my personal portfolio website built to showcase my projects, skills, and contact information.  
The design follows a clean, hand-drawn, and creative style while keeping the layout responsive and user-friendly.

## 🌐 Live Preview
👉 https://faizhasan01.github.io/portfolio

## 📌 Features
- Responsive design for desktop and mobile
- Creative hand-drawn UI theme
- Projects section with visual previews
- Interactive hover effects and animations
- Light/Dark theme toggle
- Contact form for easy communication
- Clean and readable layout

## 🛠️ Built With
- **HTML5**
- **CSS3**
- **JavaScript**
- No frameworks used

## 📂 Sections
- **Home** – Introduction with intro section
- **About** – Brief overview of me and my interests
- **Projects** – Showcases my work with visuals
- **Contact** – Simple contact form
